# \# Bob's Adventure

# 

# Bob's Adventure is my first Python project, built to learn and understand the fundamentals of programming with Python.

# 

# It is a choice-driven, text-based adventure where Bob wakes up in a strange world and must explore, fight enemies, collect items, and try to find his way home.

# 

# \## Features

# 

# \- Choice-driven exploration

# \- Turn-based combat

# \- Attack, defend, heal, and run actions

# \- Inventory system

# \- Player stats

# \- Healing potions and gold

# \- Equipment and upgrades

# \- Shops

# \- Enemy drops

# \- Ogres, goblins, rats, wizards, and other strange encounters

# \- ASCII artwork integrated into the game presentation

# 

# \## Why I Made It

# 

# This project was built as a practical way to learn Python rather than only following tutorials.

# 

# While creating Bob's Adventure, I practiced concepts including:

# 

# \- Variables and data

# \- Conditional logic

# \- Loops

# \- Functions

# \- User input

# \- Game state

# \- Inventory management

# \- Combat logic

# \- Breaking a larger program into smaller systems

# \- Debugging and troubleshooting

# 

# \## Project Files

# 

# \- `BobsAdventure.py` - Main game

# \- `BobGUi.py` - GUI/interface experimentation

# \- `BobsAdventure.ico` - Game icon

# 

# \## Status

# 

# Bob's Adventure is a playable learning project and represents my first completed Python game.

# 

# I plan to keep this repository as part of my development portfolio and as a record of my progress while learning programming and computer science.
